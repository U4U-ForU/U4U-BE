# README.md

## Project Introduction

- 아이템 제출 및 거래를 통해 사용자가 직접 서비스에 참여하는 경험을 제공한 프로젝트입니다.

## Features

- 유저
    - 회원가입&로그인
    - 마이페이지 조회
    - 닉네임 변경
    - 출석
- 아이템 제출
    - 사용자
        - 아이템 조회(상세&목록)
        - 아이템 제출 및 취소
    - 관리자
        - 아이템 제출 조회(상세&목록)
        - 제출 승인/조합 아이템 등록&거절
- 인벤토리
    - 내 아이템 전체 조회
    - 아이템 보유/예약 조회
- 뽑기
    - 아이템 뽑기
- 재조합
    - 사용자
        - 아이템 재조합
        - 조합법 조회(상세&목록)
        - 조합법 선택
    - 관리자
        - 조합법 등록/수정/삭제
        - 조합법 조회(상세&목록)
- 섞기
    - 아이템 섞기
- 거래
    - 게시물 생성/삭제
    - 게시물 제목 수정
    - 게시물 조회(상세&목록)
    - 거래 성사
    - 내 게시물 조회
    
    - 댓글 생성/삭제
    - 내 댓글 조회
